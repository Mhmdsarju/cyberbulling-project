PROJECT INFORMATION

About the Project

An explainable machine learning system for detecting and analyzing cyberbullying in English and Tanglish text.

MACHINE LEARNING PROJECT

Detect. Analyze. Explain.

This project uses multilingual text classification techniques to analyze English and Tanglish messages and identify potentially harmful communication.

Instead of providing only a binary cyberbullying prediction, the system analyzes multiple attributes of the message and produces an explainable result.

WORKFLOW

How the System Works

02 Text Features Word + Character + No-Space

MODEL ARCHITECTURE

Machine Learning Models

01

Logistic Regression

Performs the primary cyberbullying classification and provides the probability used for the displayed prediction confidence.

02

Linear SVM

Performs offense category, intent, content category, severity and target type classification.

03

Explanation Engine

Converts prediction results into human-readable explanations and communication suggestions.

Cyberbullying Safe or potentially harmful content

Content Category Personal attack, spam, privacy, misinformation and other content types
